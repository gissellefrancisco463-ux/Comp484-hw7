# HW7 Resume Site

This assignment builds on the HW6 resume site by improving its layout and spacing with reusable content wrappers, consistent padding, and a CSS box model fix. 
It uses float-based columns to organize the header and work experience, styles the profile image with rounded borders, and centers the footer with evenly spaced contact links.
